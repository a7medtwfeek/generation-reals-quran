# مُولِّد فيديوهات آيات القرآن الكريم
# Quran Verses Video Generator

تطبيق ويب محلي لإنشاء فيديوهات قصيرة احترافية لآيات القرآن الكريم مع تلاوة القراء وخلفيات جميلة.

A local web application for generating professional short videos of Quranic verses with reciter audio and beautiful backgrounds.

## ✨ المميزات | Features

- 🎙️ **اختيار القارئ** - 6 قراء مشهورين (عبد الباسط، مشاري، السديس، وغيرهم)
- 📖 **جميع السور** - دعم كامل لـ 114 سورة
- 🎨 **خلفيات احترافية** - فيديوهات عالية الجودة من Pexels API
- 📱 **تنسيق عمودي** - مناسب لـ Instagram Reels, TikTok, YouTube Shorts (1080x1920)
- 🎬 **معالجة فيديو متقدمة** - استخدام FFmpeg لدمج الصوت والفيديو والنصوص
- 🌙 **واجهة عربية** - تصميم حديث بالكامل بالعربية مع دعم RTL
- ⚡ **سريع وفعال** - معالجة محلية بدون إرسال بيانات للخارج

## 🔧 المتطلبات | Prerequisites

### 1. Python 3.8+
تأكد من تثبيت Python 3.8 أو أحدث.

### 2. FFmpeg
يجب تثبيت FFmpeg وإضافته لمسار النظام (PATH).

**تحميل FFmpeg لـ Windows:**
1. زيارة الموقع: https://www.gyan.dev/ffmpeg/builds/
2. تحميل "ffmpeg-release-full.7z"
3. فك الضغط ونسخ المجلد إلى `C:\ffmpeg`
4. إضافة `C:\ffmpeg\bin` إلى متغير البيئة PATH

**للتحقق من التثبيت:**
```bash
ffmpeg -version
```

### 3. ImageMagick (اختياري)
غير مطلوب حاليًا - نستخدم Pillow للنصوص.

6. انتظر حتى ينتهي الإنشاء (سترى شريط التقدم)

## ⚙️ الإعدادات المتقدمة

### تغيير أبعاد الفيديو
في `config.py`:
```python
VIDEO_WIDTH = 1080   # العرض
VIDEO_HEIGHT = 1920  # الارتفاع
```

### تغيير حجم الخط
```python
TEXT_FONT_SIZE = 60
```

### إضافة قارئ جديد
في `config.py` في قاموس `RECITERS`:
```python
"new_reciter": {
    "name_ar": "اسم القارئ بالعربية",
    "name_en": "Reciter Name",
    "folder": "Folder_Name_On_EveryAyah"
}
```

## 🔍 استكشاف الأخطاء | Troubleshooting

> [!NOTE]
> **للحصول على دليل استكشاف أخطاء مفصّل:**
> راجع [TROUBLESHOOTING.md](TROUBLESHOOTING.md)
> 
> **للتشخيص السريع:**
> ```bash
> python diagnose.py
> ```

### مشكلة: "FFmpeg not found"

**الحل:** تأكد من تثبيت FFmpeg وإضافته للـ PATH

### مشكلة: الخط العربي لا يظهر بشكل صحيح
**الحل:** تأكد من وجود خطوط عربية في `C:\Windows\Fonts\` أو قم بتحديث `ARABIC_FONTS` في `config.py`

### مشكلة: فشل تحميل الخلفيات
**الحل:** تحقق من اتصال الإنترنت ومفتاح Pexels API

### مشكلة: الفيديو بطيء في الإنشاء
**الحل:** هذا طبيعي - إنشاء فيديو بجودة عالية يحتاج وقت. يمكن تقليل الجودة في `config.py`:
```python
VIDEO_BITRATE = "1M"  # بدلاً من "2M"
```
